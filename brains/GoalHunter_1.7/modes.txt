# GoalHunter modes.
#
# This file is the brain's own answer to "which modes can I be run in, and
# which difficulty levels does each of them have?". The lobby reads it
# locally on every machine (brains ship with the client), fills the gear
# popup's Mode and Difficulty dropdowns from it, and hands the chosen KEYS
# to the brain as the "mode=" and "difficulty=" BRAIN_INIT_ARG tokens.
#
# Section header = the mode key. First section is mode 0, the one every
# ordinary game uses. "levels" is a comma-separated list of key:Label, and
# "default" names the level key a freshly added bot starts at.
#
# The brain applies the level in constants.lua (M.MODE_LEVELS[mode][level],
# a bundle of knob overrides applied before any preset= or cfg= token):
# hard is an empty bundle, so Hard is today's brain unchanged; medium and
# easy hand the bot handicaps.
#
# A new mode is a new section here plus its bundles in M.MODE_LEVELS. A
# scenario that wants its bots to play differently does not need a mode:
# it sends them per-bot tokens instead (the team's init table in its
# lobby template, game.bot_init), the way Survival does.

[default]
label = Default
levels = easy:Easy:1, medium:Medium:2, hard:Hard:3
default = hard
